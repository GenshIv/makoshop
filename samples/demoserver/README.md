# MakoDB ⚡ 1M Transactions Web Demo

Этот демонстрационный проект показывает возможности СУБД **MakoDB** по работе с большими объемами данных (1 000 000 транзакций) в режиме реального времени. Приложение предоставляет веб-интерфейс для загрузки данных, мониторинга импорта, мгновенного поиска с подсказками (autocomplete), пагинации и сортировки результатов.

---

## 🚀 Как запустить демонстрацию

1. Убедитесь, что вы находитесь в корневом каталоге проекта `makodb`.
2. Запустите Go-сервер:
   ```bash
   go run cmd/demoserver/main.go
   ```
3. Откройте в браузере страницу: **[http://localhost:8080](http://localhost:8080)**.
4. Выберите один из вариантов импорта:
   * Нажмите **Import Sales_Records.csv (123MB)**, чтобы загрузить предустановленный миллионный датасет напрямую с сервера.
   * Нажмите **Generate & Import 1M Rows**, чтобы сгенерировать случайные миллион транзакций на сервере «на лету» и импортировать их.
   * Перетащите свой файл CSV в зону загрузки.

## 🛠️ Архитектура и технические особенности

### 1. Бэкенд (Go, `cmd/demoserver/main.go`)
* **Мгновенный импорт без блокировок:** Традиционный конкурентный импорт во многих БД страдает от частых блокировок при записи в инвертированный индекс. В этой демонстрации импортер оптимизирован:
  * Транзакции пишутся параллельно в 16 потоков (шардов).
  * Инвертированный индекс накапливается локально в памяти каждого воркера без блокировок.
  * После завершения парсинга индекс сбрасывается в MakoDB одним быстрым последовательным пакетом.
  * **Скорость импорта 1 000 000 записей:** **~2.1 секунды** (~480 000 записей/сек).
* **Динамический маппинг колонок (Synonym Mapping):** Парсер считывает заголовки из первой строки CSV и автоматически ищет соответствия. Поддерживаются заголовки с пробелами, подчеркиваниями и синонимами (например, `Item Type`/`Category`, `Country`/`Merchant`, `Sales Channel`/`Status`).
* **Пагинация и Сортировка:** Сортировка выполняется на бэкенде в оперативной памяти перед нарезкой страниц, что гарантирует точные результаты по всему миллионному списку.

### 2. Фронтенд (HTML, CSS, JS, `cmd/demoserver/static/`)
* **Интерфейс Glassmorphism:** Реализован премиальный дизайн в темных тонах с матовым размытием (`backdrop-filter`) и неоновыми акцентами.
* **Debounced поиск:** Фильтрация результатов по 3-м полям происходит на лету по мере ввода (с задержкой в 150 мс для защиты от дребезга ввода).
* **Префиксный Autocomplete:** При вводе букв в фильтрах выпадают подсказки с сервера (уникальные значения кэшируются бэкендом при старте/после импорта).
* **Полноценная пагинация:** Кнопки «Previous» и «Next» с динамическим расчетом страниц на основе возвращаемого общего количества совпадений.

## 📊 Замеры производительности на 1 000 000 записей

* **Импорт и индексация (123 МБ CSV):** ~2.1 сек.
* **Полнотекстовый поиск (пересечение AND по индексам + фильтрация):** ~80–90 мс.
* **Подсказки (Autocomplete / Suggest):** < 1 мс.
* **Поиск без фильтров (сканирование первых страниц):** < 1 мс.

## 📈 Расчет агрегатов и статистики (сумм/средних)
Поскольку поиск по индексам в Go возвращает нам срез со всеми совпавшими ID документов (matches), мы можем прямо в теле обработчика handleTransactions сделать быстрый цикл по ним (или по первому ограниченному пулу, например, до 10 000 элементов) и рассчитать агрегатные значения:
``` go
var totalProfit float64
var totalRevenue float64
var totalUnitsSold int

for _, id := range matches {
    var tx Transaction
    if err := db.Query(id, &tx); err == nil {
        totalProfit += tx.TotalProfit
        totalRevenue += tx.TotalRevenue
        totalUnitsSold += tx.UnitsSold
    }
}
// Средняя цена: totalRevenue / float64(totalUnitsSold)
```
